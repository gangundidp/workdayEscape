# workdayEscape Monorepo

This repository contains both frontend and backend projects in a single monorepo:
- `frontend/` — Angular app
- `backend/` — backend service

## Development

### Frontend
```bash
cd frontend
npm install
npm start
```

### Backend
```bash
cd backend
npm install
npm start
```

## Root commands
```bash
npm install
npm run start:frontend
npm run start:backend
npm run build:frontend
npm run build:backend
npm run start
```
